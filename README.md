# marp_slide_design

marp形式でのスライドデザイン

## Lin

`tmp1_Lin` で制作しているスライドテーマを **Lin（リン）** と呼びます。

Lin は、凛とした知性や清潔感を表す **Rin** と、罫線を活かした整然としたレイアウトを表す **Linea** を組み合わせた名前です。広い余白、端正な文字組み、細い罫線、落ち着いた差し色によって、内容を明快に伝えることを目指しています。

主に講義、学会、研究発表など、読みやすさと信頼感が求められる場面での利用を想定しています。

### 目次の自動更新

`slides.md` に `<!-- _class: section -->` のスライドを追加した後、リポジトリのルートで次を実行します。

```sh
node scripts/update-toc.mjs
```

各SECTIONの `##` 見出しから目次が再生成され、`SECTION 01` から始まる番号も定義順に振り直されます。まとめページがある場合は、その見出しも目次の末尾へ追加されます。目次内の `AUTO-TOC` で囲まれた部分は直接編集しません。
